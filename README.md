# Daniel Abraham

I build AI applications, cryptographic prototypes, and insurance software. My background is in actuarial science; I’m interested in how software makes decisions and what evidence supports them.

## Selected work

| Project | What to look at |
| --- | --- |
| [CaseHandler](https://github.com/danielabrahamx/casehandler) | An insurance case-handling agent with deterministic checks, escalation records, and a public-case evaluation harness. Python. |
| [First-Principled](https://github.com/danielabrahamx/first-principled) | An experimental learning tool that generates concept dependency maps. Includes offline evaluations and a record of failed approaches. JavaScript. |
| [Agent Post](https://github.com/danielabrahamx/agent-post) | A shared WebGL canvas where agents publish shaders through a signed HTTP API. A Node.js server with no runtime dependencies. |
| [REPUTRANS](https://github.com/danielabrahamx/reputrans) | A reputation portability prototype combining Noir circuits, Solidity contracts, and a TypeScript API. Built with Kirill Slavin at Sibrox. |
| [Paramify](https://github.com/danielabrahamx/paramify) | A parametric insurance proof of concept: contracts, a USGS data service, and customer/admin dashboards. Solidity and TypeScript. |
| [ZeroPointAI](https://github.com/danielabrahamx/zeropointai) | A research experiment adding goal conditioning and a halting heuristic to Tiny Recursive Models. PyTorch; ARC-AGI evaluation is still outstanding. |

The repositories document their setup, implementation limits, and evaluation status. Chain-specific adaptations and earlier experiments are also public.

I’m open to engineering work on AI applications, evaluation tooling, and backend systems.
